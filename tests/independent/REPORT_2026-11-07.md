# Clean-room reconciliation: per-person XoL simulation

Built from `/home/claude/indep/SPEC.md` and the eight `param_pack.json` files only. Code: `/home/claude/indep/clean/indep_rebuild.py`
(single file; `python3 -I indep_rebuild.py <variant>...`). Nothing under `/home/claude/xolpricing` or `/home/claude/indep/variants` was read.

Per variant the folder holds `independent_iterations.csv` (option_id, iter, recovery, recovery_aboveM; iter 1..n, all four
layers, option_id from the layer record), `independent_summary.csv` (required columns plus diagnostic columns
`exact_se_mean, mc_se_mean, z_exact_vs_mc, z_cf_vs_mc, z_cf_vs_exact, exact_cov, exact_p75, exact_p95, mc_mean_aboveM`)
and `independent_diag.json` (stream first-uniforms, claim-count diagnostics, grid points, timings).

## 1. Implementation notes

### 1.1 MINSTD stream (`minstd_start`, `minstd_stream`, `verify_minstd`)
- Constants hard-coded as `A = 48271`, `M = 2**31 - 1`; Python arbitrary-precision integers throughout, `state/M` converted to
  float only at the end. `s0 = 1 + (seed % (M-1))`; `start_j = s0 * pow(A, j * 2**29, M) % M`; the stream then emits
  `state_1 = A*start_j % M, state_2 = A*state_1 % M, ...` (start_j itself is never emitted).
- Verification (`minstd_verification.json`, asserted at every run):
  - `a^(2^29) mod m` computed two ways: 3-argument `pow()` and 29 explicit modular squarings. Both give **464244102**.
  - `a^(m-1) ≡ 1` (Fermat) and `a^((m-1)/p) ≠ 1` for every prime factor p of m-1 = 2·3²·7·11·31·151·331, i.e. 48271 is a
    primitive root so the three windows (2^29 apart) are disjoint segments of one full-period cycle.
  - `start_2 = start_1 · a^(2^29)` and `start_3 = start_2 · a^(2^29)` (mod m) hold for seed 12345:
    start = [2071313096, 1551529881, 336663657].
  - 16807 is not used: the first stream-1 state for seed 12345 is 1810819990 with a=48271; it would have been 1849286602 with
    a=16807. The assertion `A == 48271 and A != 16807` is in the code.
  - First uniforms per variant are recorded in `independent_diag.json` (seed 12345: U1=0.8432287680, U2=0.1893828745, U3=0.5041389719;
    identical across all seed-12345 variants as required, different for seed777).
- Stream 1 is consumed n times (one per iteration). Streams 2 and 3 are consumed exactly ΣN times, claims laid out in
  (iteration, claim-index) order via `np.repeat(np.arange(n), N)`; iterations with N = 0 consume nothing (none occurred:
  min N was 86 at λ≈123 and 13 at λ≈31).
- Cross-variant proof of stream correctness: `designer10k` (n = 10 000, seed 12345) restricted to iterations 1..2000 reproduces
  `base` (n = 2000) **bit-for-bit** (max |diff| = 0.0 over all 8000 rows), as it must if stream positions depend only on the
  cumulative claim count.

### 1.2 Claim count
`k_max = ceil(λ + 10·sqrt(λ·(φ if NEGBIN else 1)) + 20)` (255 for base, 293 for negbin, 107 for cutoff150). Poisson /
NegBin recursions exactly as written (NegBin r = λ/(φ-1), q = 1/φ, p_0 = q^r). CDF by cumulative sum, no renormalisation
(CDF(k_max) = 1 - 1.3e-15 at base). `N = #{k : CDF(k) < U}` implemented as `np.searchsorted(cdf, U, side="left")`, which
counts exactly the entries strictly below U.

### 1.3 Severity grid (`Severity.grid`)
For k = 0..500, p_k = 10^(-k/50) and x_k = S⁻¹(p_k | X > u), computed from the analytic inverse of each conditional survival:
- **PARETO** x_k = u·p_k^(-1/α) = u·10^(k/(50α)). Asserted against `u * 10**(k/(50*alpha))` with rtol 1e-12 for every Pareto
  variant (base, seed777, negbin, cutoff150, native, designer10k).
- **GPD** x_k = u + (σ/ξ)·(p_k^(-ξ) - 1).
- **LOGNORMAL** log S_LN(x_k) = log p_k + log S_LN(u) with `log S_LN(u) = norm.logsf((ln u - μ)/σ)` evaluated in log space
  (z_u ≈ 8.30, S_LN(u) ≈ 5e-17, so the ratio must not be formed from two tiny floats); then z_k = `norm.isf(exp(·))` and
  x_k = exp(μ + σ z_k). The arguments to isf go down to ~5e-27, well inside double range, so no underflow occurs.
- Generic assertion for all three: `S(x_k | X>u)` recomputed from the forward survival equals 10^(-k/50) (rtol 1e-8).
- Rows k = 0..499: lx0_k = ln x_k, lx1_k = ln x_{k+1}. Draw: t = -50·log10(U2), k = min(floor t, 499), linear interpolation
  in ln x, X = exp. Max t observed ≈ 257 (< 499, so the clamp never binds). Cap index = floor(U3·n_fit); claim = min(X, cap).

### 1.4 Layer loss and annual aggregation
Vectorised over all claims of a run: `lim` per claim (TO_BENEFIT_LIMIT → cap - ap, 1e15 if cap ≥ 1e15; AMOUNT → limit or
1e15), `over = claim - ap`, `xl = 0 if over ≤ 0 else (min(over, lim) if lim > 0 else 0)`, times (1 - cop). Per-iteration sum
via `np.bincount(iter_idx, weights=xl, minlength=n)` (zero for iterations with no claims), then
`min(max(sum - aad, 0), aal)`. `recovery_belowM` repeats the same with `claim_belowM = min(claim, M)` but the **drawn cap**
unchanged (so `lim` for TO_BENEFIT_LIMIT is unaffected); `recovery_aboveM = recovery - recovery_belowM`.

### 1.5 Summary statistics
Sample SD (n-1), population SD (n), p_zero, mean of recovery_aboveM, quantiles by nearest rank
(`sorted[max(1, ceil(q·n)) - 1]`, 1-based position).

### 1.6 Independent Monte Carlo (`mc_run`)
`numpy.random.default_rng(20261107)`, 200 000 iterations, same seed for every variant (so variants that share a model —
base / seed777 / native / designer10k — have identical MC columns by construction). Counts from `rng.poisson(λ)` or
`rng.negative_binomial(r, q)` (numpy's P(0) = q^r, mean = r(1-q)/q = λ: same parametrisation as the spec). Severity by the
**exact** inverse survival (no grid), cap by `rng.integers(0, n_fit)`. Same layer code as the exact run. This therefore also
tests that the 50-points-per-decade log-linear grid introduces no detectable bias for GPD and lognormal (it is exact for
Pareto).

### 1.7 Closed form (`closed_form`)
`λ · (1/n_fit) · Σ_c ∫_ap^{min(ap+lim_c, c)} S(x | X>u) dx · (1-cop)`, `scipy.integrate.quad` per cap with break-points at u
and M when inside the interval; `belowM` version with upper limit also min(·, M). For Pareto this was cross-checked
against the analytic ∫(u/x)^α dx = u^α (x^{1-α})/(1-α): layer 1 analytic 6 751 589.386129 vs quad 6 751 589.386129;
layer 3 analytic 9 689 854.940566 vs quad 9 689 854.940566.

## 3. Ambiguities in the spec and the assumptions taken

1. **Severity parameters source.** `selected_candidate.p1/p2` are strings; I parse them as floats. For `native` the spec says to
   use `pareto_alpha_native` — here it equals the selected α so the outputs are identical to base. For `cutoff150` the two differ
   in the 16th digit (1.6162358030875845 vs ...847); I used `selected_candidate` since `severity_source` = PYTHON. No visible effect.
2. **S(x | X>u) for x < u.** The spec only defines the survival for x ≥ u. In `cutoff150` (u = 150k) layers 1 and 3 attach at
   100k and 75k, below u. Since every simulated claim is above u, I take S(x) = 1 for x < u in the closed form (so the
   integral from 75k to 150k contributes the full 75k per claim), which is what the simulation implies. The three estimates
   agree on this variant, confirming the reading.
3. **Negative/zero-width intervals in the closed form.** When `ap ≥ c` (e.g. ap = 250k vs cap 150k) the integral is taken as 0
   (claims capped at 150k never reach the layer). Implied by the simulation, not stated.
4. **`co_participation_pct` units.** Blank in every layer, so moot; I treat a value as a fraction (`xl *= 1 - cop`) as
   written in the spec's formula, not as a percentage/100.
5. **`lim > 0` guard.** For TO_BENEFIT_LIMIT with cap ≤ ap (e.g. option 4, ap = 150k, caps 149 999.59 and 150 000) lim ≤ 0 →
   xl = 0. Applied exactly as written; the closed form mirrors it by skipping caps with lim ≤ 0.
6. **"Unlimited if cap ≥ 1e15".** No cap in any pack is ≥ 1e15, so this branch is never exercised.
7. **Quantile position for n = 2000, q = 0.995** gives position 1990 (ceil(1990.0) = 1990); I rely on exact float arithmetic
   here (0.995·2000 = 1990.0 exactly in double) — no epsilon added, as the spec gives none.
8. **MC generator choice** is unspecified beyond "numpy default_rng, 200 000 iterations"; seed 20261107 chosen and fixed.
9. **`cdf_tail`.** CDF(k_max) < 1 by ~1e-15; a U above it would give N = k_max + 1. Impossible for U = state/m ≤ 1 - 4.7e-10
   given CDF(k_max) = 1 - 1.3e-15, so there is no edge case. Not an ambiguity, recorded for completeness.
10. **Reinstatements, AAD, AAL** are all blank; the code implements AAD/AAL per spec but these paths are not exercised here.
    Reinstatements are not implemented (spec: usage = 0).

No point was found where the spec is self-contradictory.
